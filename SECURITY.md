# Sécurité

## Versions maintenues

Seule la dernière version publiée reçoit des correctifs de sécurité.

## Signaler une vulnérabilité

N'ouvre pas d'issue publique avec les détails d'une vulnérabilité. Utilise le signalement privé de vulnérabilité GitHub du dépôt. Si cette option n'est pas disponible, contacte le mainteneur par un canal privé.

Indique la version concernée, les étapes de reproduction, l'impact observé et, si possible, une piste de correction. N'ajoute aucune donnée réelle ou sensible à ton rapport.

Le projet confirmera la réception, évaluera le problème et publiera un correctif avant de rendre les détails publics.
